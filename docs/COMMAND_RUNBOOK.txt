9. Load all 23 files into the 8001 test site
---------------------------------------------

Start 8001 first with IP_SAKTI_TEST_MODE=true. Then run this PowerShell block
from the repository root. It submits all .txt and .pdf files in data/corpus to
the same ingestion pipeline used by the UI:

  $files = Get-ChildItem -LiteralPath data\corpus -Recurse -File | Where-Object { $_.Extension -in '.txt','.pdf' } | Sort-Object FullName
  $sources = foreach ($f in $files) {
    $rel = $f.FullName.Substring((Resolve-Path .).Path.Length + 1)
    $lower = $rel.ToLowerInvariant()
    $type = 'act'; $tier = 'TIER_1'
    if ($lower -match '\\rules\\') { $type='rule'; $tier='TIER_2' }
    elseif ($lower -match '\\forms\\') { $type='formulary'; $tier='TIER_5' }
    elseif ($lower -match 'protocol|nagoya') { $type='protocol' }
    elseif ($lower -match 'treaty|agreement|pct|cbd_1992') { $type='treaty' }
    $jurisdiction = if ($lower -match '\\wipo\\|\\cbd_nagoya\\') { 'INTERNATIONAL' } else { 'INDIA' }
    [ordered]@{ source_id=$f.Name; source_type=$type; file_path=$f.FullName; jurisdiction=$jurisdiction; authority_tier=$tier; language='en'; metadata=@{ corpus_path=$rel; bulk_seed=$true } }
  }
  $payload = @{ sources=@($sources); options=@{ replace_existing=$false; source='full_corpus_seed' }; priority=0 } | ConvertTo-Json -Depth 8
  $response = Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8001/ingest/batch' -ContentType 'application/json' -Body $payload
  $response | ConvertTo-Json -Depth 4

Copy the returned job_id into this status command:

  $job='PASTE_JOB_ID_HERE'
  Invoke-RestMethod "http://127.0.0.1:8001/ingest/$job/status" | ConvertTo-Json -Depth 5

Verify the full test corpus:

  $h=Invoke-RestMethod 'http://127.0.0.1:8001/health'
  $v=$h.components | Where-Object name -eq 'vector_store'
  $d=Invoke-RestMethod 'http://127.0.0.1:8001/documents?limit=100'
  "health=$($h.status) documents=$($d.total) chunks=$($v.details.total_chunks) vectors=$($v.details.total_vectors)"

Expected after a clean load:

  health=healthy documents=23 chunks=2299 vectors=2299

13. Run a 90-execution expansion
---------------------------------

This creates three focused variants for each of the 30 base cases (90 total)
without modifying the checked-in 30-case source file:

  $out='artifacts\prompt-runs\prompt_suite_90.txt'
  New-Item -ItemType Directory -Force -Path (Split-Path $out) | Out-Null
  $suffixes=@('Focus especially on classification, authority, and immediate registration steps.','Focus especially on patentability, prior art, traditional knowledge, and ownership risks.','Focus especially on evidence, citations, jurisdiction boundaries, compliance risks, and practical next actions.')
  $lines=Get-Content 'docs\prompt_suite_30.txt'
  $outLines=[System.Collections.Generic.List[string]]::new()
  foreach($line in $lines){if([string]::IsNullOrWhiteSpace($line)-or$line.StartsWith('#')){continue};$parts=$line -split "`t",5;if($parts.Count -lt 5){continue};for($i=0;$i-lt 3;$i++){$outLines.Add(("{0}_v{1}`t{2}`t{3}`t{4}`t{5} {6}" -f $parts[0],($i+1),$parts[1],$parts[2],$parts[3],$parts[4],$suffixes[$i]))}}
  Set-Content -LiteralPath $out -Value $outLines -Encoding utf8

Run it against 8001 for a fast workflow test:

  PYTHON_BIN='/mnt/c/Users/vvars/OneDrive/Desktop/sih rag/.venv-fixed/Scripts/python.exe' BASE_URL='http://127.0.0.1:8001' bash scripts/run_prompt_suite.sh '/mnt/c/Users/vvars/OneDrive/Desktop/sih rag/artifacts/prompt-runs/prompt_suite_90.txt'

Run it against 8000 only when real NVIDIA usage and the longer runtime are
acceptable:

  PYTHON_BIN='/mnt/c/Users/vvars/OneDrive/Desktop/sih rag/.venv-fixed/Scripts/python.exe' BASE_URL='http://127.0.0.1:8000' bash scripts/run_prompt_suite.sh '/mnt/c/Users/vvars/OneDrive/Desktop/sih rag/artifacts/prompt-runs/prompt_suite_90.txt'

18. Common troubleshooting
---------------------------

Root shows JSON instead of the site:

  Refresh the browser and open http://127.0.0.1:8000/ or
  http://127.0.0.1:8001/. The root route redirects to /web/.

Dashboard shows zero prompts:

  Confirm the browser port matches the server that received the queries.
  Check /dashboard/metrics. Test mode and production mode have separate
  process-local query counters; production aggregate telemetry is persisted,
  while test telemetry is intentionally ephemeral.

Files page is empty on 8001:

  Re-run the full-corpus ingestion block in section 9. The test vector store is
  in memory and resets on restart.

NVIDIA generation fails:

  Check that .env contains NVIDIA_API_KEY, that IP_SAKTI_TEST_MODE=false, and
  that the configured NVIDIA model/base URL are valid. Never print the key.

Port already in use:

  Use the port check in section 7 and either use the running server or stop the
  process intentionally using section 17.

Test suite returns invalid JSON:

  Confirm the API is running, use the fixed .venv-fixed interpreter, and check
  the generated log under artifacts/prompt-runs/.
